# X担当へ（引き渡し置き場）

Muse（相棒）が毎日の成果物をここに置きます。クロードのX担当は、ここから受け取ってください。このリポジトリは公開設定です（置くのは投稿用の素材だけです）。

## 置かれるもの（毎日・日付フォルダ `YYYY-MM-DD/`）
- リール動画（mp4）とカバー画像
- X投稿文（`x-posts.md`、コピペで投稿できる形）
- 指示書（Claude Code作成、sheet-1 / sheet-2）
- その日に渡したい告知文など（あれば）

## 運用ルール
- 各日付フォルダの `README.md` がその日の目次です。
- 投稿が済んだ日の動画ファイルは、容量節約のため削除して構いません（指示書と投稿文は残す）。
- 動画はInstagramとXの両方に使える縦型（1080×1920）です。
